# Contributing

Thanks for your interest in the FileSpin plugin.

This repository is published from FileSpin's internal source with each
release, so we don't merge pull requests here. If you'd like a change, please
open an [issue](https://github.com/FileSpin-io/filespin-agent-plugin/issues)
describing it, and we'll take it from there.

- **Bugs:** say which agent you use (Claude Code, Codex or Cursor) and its
  version, what you asked, and what happened.
- **Wrong or missing FileSpin answers:** include the question and, if you can,
  the docs page that has the right answer.
- **Account or billing questions:** email support@filespin.io.
- **Security issues:** don't open an issue; see [SECURITY.md](SECURITY.md).
